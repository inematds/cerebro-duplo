Qué es

El mismo cerebro, sin convertirse en dos

Tu segundo cerebro (la carpeta Markdown del kit astra-2cerebro) puede ser leído por Claude Code y Codex. Cada uno entra por una puerta diferente: CLAUDE.md e .claude/skills de un lado, AGENTS.md e .agents/skills en el otro. cerebro-duplo mantiene iguales las interfaces y decide cuál usar.

🪞 Paridad

duplo.sh verificar comprueba que AGENTS.md = CLAUDE.md, que cada skill está reflejada byte por byte y que cada una tiene el openai.yaml de Codex. sync lo corrige. La skill duplo-verificar informa y propone, sin hacer cambios por sí sola.

🧭 Enrutamiento

La skill qual-agente lee la solicitud, elige agente + modelo + esfuerzo con una tabla (MCP configurado, repo abierto, razonamiento pesado, tarea rutinaria barata) y devuelve el comando. Los perfiles .env guardan el modelo y el esfuerzo por tipo de tarea.

📒 Uso y cuota

uso registrar anota cada sesión en registro-uso.md; uso resumo suma por agente y perfil. Sin inventar precios: aquí, minutos y sesiones; el dinero, en la tabla del proveedor.

Cómo funciona

Del pedido al registro

Un ciclo corto, repetido en cada sesión. Las flags de modelo y esfuerzo son las reales de ambos CLI (leídas de --help): --model/--effort en Claude Code, -m/-c model_reasoning_effort en Codex.

solicitud→ /qual-agente o $qual-agente→ agente + perfil→ duplo.sh claude|codex <perfil>→ trabajo en el cerebro→ duplo.sh sync→ duplo.sh uso registrar
1

Enrutar

MCP específico → el agente que lo tiene. Código → donde está abierto el repo. Auditoría, arquitectura, wiki extensa → raciocinio. Buscar, resumir, redactar → rotina.

2

Abrir

duplo.sh claude raciocinio imprime y ejecuta cd cérebro && claude --model fable --effort high. --so-mostrar solo imprime.

3

Sincronizar

¿Editaste el manual o una skill? sync vuelve a generar el espejo a partir del canónico (AGENTS.md, .claude/skills). Nunca borra; avisa.

4

Registrar

Una línea por sesión: agente, perfil, modelo, esfuerzo, minutos, tarea. El jueves, uso resumo indica dónde se fue la cuota.

Guía de uso · paso a paso

Instalar, verificar, enrutar, registrar

Comandos reales. Reemplaza ~/meu-cerebro por la carpeta de tu cerebro.

1

Instalar en el cerebro

Clona el repo y copia las dos skills en .claude/skills e .agents/skills, e o duplo.sh (con perfis/ e modelos/) para scripts/. Ejecuta el verificar al final.

git clone https://github.com/inematds/cerebro-duplo.git
cd cerebro-duplo
bash instalar.sh ~/meu-cerebro
2

Verificar la paridad

Manual idéntico, skills sincronizadas, openai.yaml presente, rutas del manual válidas. Código 1 si hay un PROBLEMA; una ruta rota es solo una ADVERTENCIA (el /iniciar crea varios archivos después).

cd ~/meu-cerebro
bash scripts/duplo.sh verificar
# OK: AGENTS.md y CLAUDE.md son idénticos
# OK: 10 skills idénticas en ambos lados
# == resultado: 0 problema(s), 6 aviso(s)
3

Ajustar los perfiles a tu plan

Los nombres de modelo que vienen en el repo son los de esta máquina. Edita scripts/perfis/*.env. Fuentes confiables: claude --help (aliases fable, opus, sonnet; esfuerzo low…max) y tu ~/.codex/config.toml.

bash scripts/duplo.sh perfis
#   codigo       claude: claude-opus-5-5/high     codex: gpt-6-astra/high
#   predeterminado       claude: sonnet/medium  codex: gpt-6-astra/medium
#   razonamiento   claude: claude-opus-5-5/high   codex: gpt-6-astra/high
#   rutina       claude: sonnet/low     codex: gpt-6-astra/low
nano scripts/perfis/padrao.env
4

Preguntar qué agente usar

En cualquier sesión. La skill responde en cuatro líneas: agente · perfil · modelo/esfuerzo, dos motivos, el comando y la línea de registro para el final.

# en Claude Code
/qual-agente preciso auditar o cérebro, faz um mês que não rodo
# en Codex
$qual-agente preciso auditar o cérebro, faz um mês que não rodo

# respuesta típica:
# codex · raciocinio · gpt-6-astra/high
# La auditoría requiere un razonamiento intenso: un modelo barato infla la calificación.
# Codex porque Claude Code ya consumió más cuota esta semana.
# bash scripts/duplo.sh codex raciocinio
# al cerrar: bash scripts/duplo.sh uso registrar codex raciocinio 25 "auditoria mensual"
5

Abrir el agente con el perfil

El script imprime el comando antes de ejecutarlo. Con --so-mostrar solo imprime (útil para revisar las flags sin gastar cuota).

bash scripts/duplo.sh claude raciocinio --so-mostrar
# comando: cd ~/meu-cerebro && claude --model fable --effort high --name duplo:raciocinio

bash scripts/duplo.sh codex rotina --so-mostrar
# comando: codex -C ~/meu-cerebro -m gpt-6-astra -c model_reasoning_effort=\"low\"

bash scripts/duplo.sh codex raciocinio      # se abre de verdad
6

Sincronizar después de editar

Edita siempre el canónico (AGENTS.md, .claude/skills/...). O sync vuelve a generar el otro lado. --fonte claude invierte el sentido del manual cuando la edición buena está en el CLAUDE.md.

bash scripts/duplo.sh sync                  # AGENTS.md → CLAUDE.md; .claude/skills → .agents/skills
bash scripts/duplo.sh sync --fonte claude   # CLAUDE.md → AGENTS.md
bash scripts/duplo.sh verificar             # 0 problema(s)
7

Registrar el uso y leer el resumen

Una línea por sesión en registro-uso.md (creado a partir de la plantilla la primera vez). El resumen es lo que alimenta la regla de cuota: si la semana está apretada, se baja un nivel o se cambia de agente.

bash scripts/duplo.sh uso registrar codex raciocinio 25 "auditoria mensal"
bash scripts/duplo.sh uso registrar claude rotina 8 "resumo reunião 06/09"
bash scripts/duplo.sh uso resumo
# | Agente | Sesiones | Minutos |
# | claude | 1 | 8 |
# | codex  | 1 | 25 |
# total: 2 sesiones, 33 minutos
8

Informe de paridad del agente

La skill duplo-verificar ejecuta el verificar y convierte la salida en un informe breve con una corrección por elemento. No corrige por sí sola: termina preguntando si puede aplicar los cambios.

/duplo-verificar       # Claude Code
$duplo-verificar       # Codex
